# Music Knowledge Graph

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Music knowledge graph extracted through an automated process from Web Data Commons datasets (Microdata and JSON-LD). The pipeline includes a robust deduplication process and heavy data cleaning.

## Dataset Overview

Provided knowledge graph is in N-Triples format. It consists of `MusicRecording`, `MusicAlbum`, `MusicGroup` and `MusicEvent` classes from Schema.org vocabulary.
The data is published in separate parts using GZIP compression.
